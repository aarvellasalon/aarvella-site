AARVELLA SERVICE WEBPAGES PACK - FORMATTED VERSION
====================================================

This version keeps the same page structure and filenames, but the HTML, CSS, and JavaScript have been reformatted with clear indentation and line breaks for easier editing.

Files included:
- services.html
- hair.html
- beauty.html
- spa.html
- makeup.html
- styles.css
- app.js

How to use:
1. Upload all files into the same folder on your website.
2. Keep styles.css and app.js in the same folder unless you update the paths inside the HTML files.
3. Replace the placeholder images with Aarvella's real salon images.
4. Connect the booking popup form to your CRM or booking software.

Editing tips:
- Header and footer are repeated inside every HTML page.
- Global styling is in styles.css.
- Booking popup and mobile menu behavior are in app.js.
- To update prices, edit the <div class="price-row"> blocks inside each page.
